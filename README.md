# File Handling Projects in Python

This repository contains basic file handling programs in Python as part of a practice assignment.

## Task 1: Read a File and Handle Errors

- **Description**:  
  This program tries to open and read a file named `sample.txt`.
- **Features**:
  - Prints the file content line by line.
  - Gracefully handles the case if the file does not exist by displaying an error message.

## Task 2: Write and Append Data to a File

- **Description**:  
  This program:
  - Takes user input and writes it into a file named `output.txt`.
  - Appends additional user input to the same file.
  - Reads and displays the final content of the file.

## How to Run

1. Clone the repository or download the files.
2. Ensure Python is installed on your machine.
3. Run each script individually:
   - For Task 1: `python task1_read_file.py`
   - For Task 2: `python task2_write_append.py`
